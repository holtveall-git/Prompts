# Content Creation Prompts

## Blog Post Generation
```
Write a comprehensive blog post about:

Topic: [TOPIC]
Target Audience: [AUDIENCE]
Tone: [Professional/Casual/Technical/etc.]
Length: [WORD COUNT]
Key Points to Cover: [LIST POINTS]

Include:
- Engaging introduction
- Well-structured body with subheadings
- Practical examples
- Conclusion with call-to-action
- SEO-optimized keywords naturally integrated
```

## Article Outline
```
Create a detailed outline for an article about:

Topic: [TOPIC]
Article Type: [How-to/Listicle/Opinion/Analysis/etc.]
Target Length: [WORDS]

Provide:
1. Compelling title options (3-5)
2. Introduction hook
3. Main sections with subsections
4. Key points for each section
5. Conclusion summary
```

## Social Media Content
```
Create social media content for:

Platform: [Twitter/LinkedIn/Instagram/Facebook]
Topic/Message: [DESCRIBE]
Brand Voice: [DESCRIBE]
Goal: [Awareness/Engagement/Conversion/etc.]

Generate:
- 5 post variations
- Relevant hashtags
- Call-to-action
- Optimal posting times suggestion
```

## Email Newsletter

Write an email newsletter:

Tone: [TONE]

Include:

```

## Product Descriptions
```
Write compelling product descriptions:

Product: [PRODUCT NAME]
Features: [LIST FEATURES]
Benefits: [LIST BENEFITS]
Target Customer: [DESCRIBE]
Unique Selling Points: [USPs]

Create:
- Short description (50 words)
- Long description (200 words)
- SEO keywords
- Bullet points highlighting key features
```

Topic: [TOPIC]

```

Target Audience: [DESCRIBE]
Goal: [Conversions/Sign-ups/etc.]

## Case Study
```
Write a case study:

Client/Company: [NAME]
Challenge: [PROBLEM FACED]
Solution: [WHAT WAS DONE]
Results: [OUTCOMES WITH METRICS]

Structure:
- Executive summary
- Background
- Challenge details
- Solution approach
- Implementation
- Results with data
- Testimonial
- Key takeaways
```

## Press Release
```
Write a press release for:

Announcement: [WHAT'S BEING ANNOUNCED]
Company: [COMPANY NAME]
Key Details: [IMPORTANT INFORMATION]
Quote Source: [WHO SHOULD BE QUOTED]
Date: [RELEASE DATE]

Follow standard press release format:
- Headline
- Dateline
- Lead paragraph (who, what, when, where, why)
- Body paragraphs
- Boilerplate
- Contact information
```
