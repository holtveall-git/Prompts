# Debugging Prompts

## General Debugging
```
I'm encountering an error in my code. Help me debug it:

Error Message: [PASTE ERROR]
Code: [PASTE CODE]
Expected Behavior: [DESCRIBE]
Actual Behavior: [DESCRIBE]
Environment: [OS, language version, dependencies]

Please:
1. Identify the root cause
2. Explain why it's happening
3. Provide a fix with explanation
4. Suggest how to prevent similar issues
```

## Stack Trace Analysis
```
Analyze this stack trace and help me identify the issue:

Stack Trace:
[PASTE STACK TRACE]

Context:
[DESCRIBE WHAT YOU WERE DOING]

Code snippets from relevant files:
[PASTE RELEVANT CODE]
```

## Intermittent Bug Investigation
```
I have an intermittent bug that's hard to reproduce:

Bug Description: [DESCRIBE]
Frequency: [HOW OFTEN]
Steps to Reproduce: [STEPS]
Code: [PASTE CODE]

Help me:
1. Identify potential race conditions
2. Find timing-related issues
3. Suggest debugging strategies
4. Add logging/monitoring points
```

## Production Issue Investigation
```
We have a production issue:

Symptoms: [DESCRIBE]
Logs: [PASTE RELEVANT LOGS]
Metrics: [ANY PERFORMANCE METRICS]
Recent Changes: [WHAT CHANGED]
Code: [PASTE RELEVANT CODE]

Help me:
1. Diagnose the issue
2. Identify the root cause
3. Suggest immediate mitigation
4. Provide a long-term fix
```

## Memory Leak Detection
```
I suspect a memory leak in this code:

Code: [PASTE CODE]
Memory Pattern: [DESCRIBE MEMORY USAGE]
Environment: [RUNTIME DETAILS]

Help me:
1. Identify potential memory leaks
2. Explain what's causing them
3. Suggest fixes
4. Recommend profiling approaches
```

## Logic Error Investigation
```
The logic isn't working as expected:

Code: [PASTE CODE]
Test Case: [INPUT]
Expected Output: [OUTPUT]
Actual Output: [OUTPUT]

Walk through the execution step by step and identify where the logic goes wrong.
```
