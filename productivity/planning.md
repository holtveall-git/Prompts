# Planning Prompts

## Project Plan
```
Create a project plan for:

Project: [NAME]
Objective: [GOAL]
Scope: [WHAT'S INCLUDED/EXCLUDED]
Timeline: [DURATION]
Team: [PEOPLE INVOLVED]
Budget: [RESOURCES]

Develop:
1. Project phases and milestones
2. Detailed task breakdown (WBS)
3. Dependencies and critical path
4. Resource allocation
5. Risk assessment and mitigation
6. Success metrics
7. Communication plan
8. Stakeholder management approach
```

## Sprint Planning
```
Plan the next sprint:

Sprint Duration: [WEEKS]
Team Capacity: [STORY POINTS]
Product Backlog: [PASTE OR DESCRIBE]
Previous Sprint Velocity: [POINTS]
Sprint Goal: [OBJECTIVE]

Create:
- Sprint backlog with prioritized stories
- Task breakdown for each story
- Capacity allocation per person
- Definition of done
- Sprint risks and dependencies
- Daily standup structure
```

## Strategic Plan
```
Develop a strategic plan for:

Organization/Department: [NAME]
Time Horizon: [1-3 YEARS]
Current State: [SITUATION]
Desired Future State: [VISION]

Include:
1. Mission and vision statement
2. SWOT analysis
3. Strategic objectives (3-5)
4. Key initiatives for each objective
5. KPIs and success metrics
6. Resource requirements
7. Timeline and milestones
8. Risk factors
9. Governance structure
```

## Product Roadmap
```
Create a product roadmap for:

Product: [NAME]
Time Horizon: [6-18 MONTHS]
Vision: [PRODUCT VISION]
Current State: [WHAT EXISTS]
Key Stakeholders: [WHO CARES]

Structure:
- Now (0-3 months): [THEMES]
- Next (3-6 months): [THEMES]
- Later (6+ months): [THEMES]

For each theme:
- Strategic rationale
- Key features
- Success metrics
- Dependencies
- Confidence level
```

## OKR Development
```
Develop OKRs (Objectives and Key Results) for:

Team/Organization: [NAME]
Time Period: [QUARTER/YEAR]
Strategic Priorities: [FOCUS AREAS]
Current Challenges: [CONTEXT]

Create:
- 3-5 Objectives (ambitious, qualitative goals)
- 3-5 Key Results per Objective (measurable outcomes)
- Confidence level for each KR
- Initiatives/projects to achieve KRs
- Dependencies and risks
- Alignment with company/department OKRs
```
