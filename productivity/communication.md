# Communication Prompts

## Professional Email
```
Write a professional email:

To: [RECIPIENT]
Purpose: [REASON FOR EMAIL]
Context: [BACKGROUND]
Tone: [FORMAL/FRIENDLY/etc.]
Key Points: [WHAT TO COMMUNICATE]

Structure:
- Subject line (clear and specific)
- Greeting
- Opening (context)
- Body (main points)
- Action items or ask
- Closing

Make it clear, concise, and actionable.
```

## Difficult Conversation Script
```
Help me prepare for a difficult conversation:

Situation: [DESCRIBE]
Person: [RELATIONSHIP/ROLE]
Goal: [WHAT YOU WANT TO ACHIEVE]
Concerns: [WHAT MIGHT GO WRONG]
Facts: [OBJECTIVE INFORMATION]

Provide:
1. Opening statement
2. Key points to communicate
3. Active listening prompts
4. Response to potential reactions
5. Questions to ask
6. How to stay calm and professional
7. Desired outcome and next steps
```

## Presentation Outline
```
Create a presentation outline for:

Topic: [SUBJECT]
Audience: [WHO THEY ARE]
Duration: [TIME]
Goal: [INFORM/PERSUADE/INSPIRE/etc.]
Key Message: [MAIN TAKEAWAY]

Structure:
1. Opening hook
2. Agenda overview
3. Main sections with key points
4. Supporting data/examples
5. Objection handling
6. Call to action
7. Q&A preparation
8. Closing with memorable takeaway

Include suggestions for visuals.
```

## Feedback Delivery
```
Help me deliver feedback:

Person: [RECIPIENT]
Situation: [WHAT HAPPENED]
Impact: [CONSEQUENCES]
Type: [CONSTRUCTIVE/POSITIVE/MIXED]
Goal: [IMPROVEMENT/RECOGNITION/etc.]

Use SBI framework (Situation-Behavior-Impact):
1. Describe the situation
2. Explain the specific behavior
3. Describe the impact
4. Discuss next steps or appreciation

Make it specific, actionable, and balanced.
```

## Status Update
```
Write a status update:

Project/Work: [NAME]
Audience: [STAKEHOLDERS]
Period: [TIME FRAME]
Format: [EMAIL/SLIDE/DOC]

Include:
1. Summary (TL;DR)
2. Accomplishments
3. In progress
4. Upcoming
5. Metrics/progress toward goals
6. Risks or blockers
7. Decisions needed
8. Questions or asks

Make it scannable and highlight what needs attention.
```

## Apology Letter
```
Write a sincere apology:

Situation: [WHAT HAPPENED]
To: [RECIPIENT]
Impact: [HOW IT AFFECTED THEM]
Responsibility: [YOUR ROLE]

Include:
1. Acknowledge the mistake
2. Take responsibility (no excuses)
3. Express understanding of impact
4. Sincere apology
5. Explanation (brief, not excuse)
6. Remedy or compensation
7. Prevention (how you'll ensure it doesn't happen again)
8. Request for forgiveness (if appropriate)

Tone: Genuine, humble, professional.
```

```
Meeting Type: [PURPOSE]

Provide:
```

## Negotiation Preparation
```
Prepare me for a negotiation:

Negotiation Type: [SALARY/CONTRACT/DEAL/etc.]
What's at Stake: [SUBJECT]
Your Position: [WHAT YOU WANT]
Their Likely Position: [WHAT THEY WANT]
BATNA: [BEST ALTERNATIVE]

Prepare:
1. Research and background
2. Your goals (ideal, target, walk-away)
3. Their interests and constraints
4. Value creation opportunities
5. Opening offer strategy
6. Concession strategy
7. Common ground to build on
8. Tactics they might use
9. Counter-arguments prepared
10. Closing strategies
```

## Announcement Message
```

What: [WHAT'S BEING ANNOUNCED]
Audience: [WHO NEEDS TO KNOW]
Impact: [HOW IT AFFECTS THEM]
Tone: [EXCITING/SERIOUS/INFORMATIVE/etc.]
Channel: [EMAIL/SLACK/ALL-HANDS/etc.]

Structure:
```

## Conflict Resolution Framework
```
Help resolve this conflict:

Parties: [WHO'S INVOLVED]
Conflict: [DESCRIBE DISAGREEMENT]
Underlying Interests: [WHAT EACH SIDE REALLY WANTS]
Constraints: [LIMITATIONS]

Provide:
1. Reframe the conflict
2. Identify common ground
3. Explore interests behind positions
4. Generate options for mutual gain
5. Objective criteria for evaluation
6. Proposed solutions
7. Communication approach
8. Process for agreement
```

## Stakeholder Communication Plan
```
Create a stakeholder communication plan for:

Project/Initiative: [NAME]
Stakeholders: [LIST GROUPS]
Duration: [TIMELINE]
Key Messages: [WHAT TO COMMUNICATE]

For each stakeholder group:
1. Interests and concerns
2. Key messages
3. Communication frequency
4. Channels to use
5. Level of detail
6. Who communicates
7. When to communicate
8. Success metrics
9. Feedback mechanism
```

## Internal Memo
```
Write an internal memo:

To: [RECIPIENTS]
From: [YOUR ROLE]
Subject: [TOPIC]
Purpose: [WHY YOU'RE WRITING]

Format:
- Header (To, From, Date, Subject)
- Purpose statement
- Background/context
- Discussion/details
- Conclusion/recommendation
- Action items
- Attachments (if any)

Tone: Clear, direct, professional.
```

## Elevator Pitch
```
Create an elevator pitch for:

What: [PRODUCT/COMPANY/IDEA]
Audience: [INVESTORS/CUSTOMERS/PARTNERS]
Duration: [30/60 SECONDS]

Structure:
1. Hook (attention grabber)
2. Problem you solve
3. Your solution
4. Why you're different/better
5. Proof/traction
6. Ask or call to action

Make it memorable, clear, and compelling.
```

## Crisis Communication
```
Draft crisis communication for:

Crisis: [WHAT HAPPENED]
Impact: [WHO'S AFFECTED]
Audiences: [STAKEHOLDERS]
Channel: [WHERE TO COMMUNICATE]

Create:
1. Holding statement (immediate)
2. Full statement (detailed)
3. FAQs
4. Talking points for spokespeople
5. Internal communication (to employees)
6. Customer communication
7. Media response (if applicable)
8. Social media strategy
9. Update schedule
10. Message monitoring approach

Tone: Transparent, empathetic, factual, responsible.
```
