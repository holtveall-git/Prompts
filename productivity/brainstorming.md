# Brainstorming Prompts

## Idea Generation
```
Generate creative ideas for:

Challenge/Opportunity: [DESCRIBE]
Context: [BACKGROUND]
Constraints: [LIMITATIONS IF ANY]
Target Audience: [WHO IS THIS FOR]

Generate:
- 20+ diverse ideas
- Mix of incremental and radical ideas
- Consider different approaches and angles
- Brief explanation for each idea
- Highlight top 5 most promising
```

## Feature Brainstorming
```
Brainstorm features for:

Product/Service: [NAME]
Current State: [WHAT EXISTS]
User Problems: [PAIN POINTS]
Goals: [OBJECTIVES]

Generate ideas for:
1. Must-have features
2. Nice-to-have features
3. Innovative differentiators
4. Quick wins
5. Long-term vision features

For each, note: value, effort, and priority.
```

## Problem-Solving Session
```
Help me solve this problem:

Problem: [DESCRIBE PROBLEM]
Context: [BACKGROUND]
What's been tried: [PREVIOUS ATTEMPTS]
Constraints: [RESOURCES, TIME, ETC.]

Approach using:
1. Problem reframing
2. First principles thinking
3. Analogies from other domains
4. Reverse thinking (what would make it worse?)
5. Multiple solution approaches
6. Pros/cons of each approach
```

Generate name ideas for:

## Scenario Planning
```
Develop scenarios for:

Context: [SITUATION]
Time Horizon: [YEARS AHEAD]
Key Uncertainties: [FACTORS]

Create:
1. Best case scenario
2. Worst case scenario
3. Most likely scenario
4. Black swan scenario

For each:
- Describe the world in this scenario
- Key events that led there
- Implications for [ORGANIZATION/DECISION]
- Strategic responses
```

## User Story Generation
```
Generate user stories for:

Feature: [FEATURE NAME]
User Personas: [WHO WILL USE IT]
Jobs to Be Done: [USER GOALS]

Create user stories in format:
"As a [user type], I want to [action] so that [benefit]"

Include:
- Core user stories
- Edge cases
- Acceptance criteria
- Priority (must have / should have / nice to have)
- Story points estimate
```

## SCAMPER Method Application
```
Apply SCAMPER to improve:

Product/Service/Process: [DESCRIBE]

Explore:
- Substitute: What can be substituted?
- Combine: What can be combined?
- Adapt: What can be adapted from elsewhere?
- Modify: What can be modified or magnified?
- Put to other use: What else can it be used for?
- Eliminate: What can be removed?
- Reverse: What can be rearranged or reversed?

Generate specific ideas for each lens.
```
