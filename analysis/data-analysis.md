# Data Analysis Prompts

## Dataset Overview
```
Analyze this dataset and provide an overview:

[PASTE DATA or DESCRIBE DATASET]

Provide:
1. Dataset structure (rows, columns, data types)
2. Statistical summary of numerical columns
3. Distribution of categorical variables
4. Missing values analysis
5. Potential data quality issues
6. Initial insights
7. Recommendations for cleaning/preprocessing
```

## Statistical Analysis
```

Data:
[PASTE DATA]

Question to answer: [SPECIFIC QUESTION]

Provide insights and visualizations suggestions.
```
