# Summarization Prompts

## Document Summary
```
Summarize this document:

[PASTE DOCUMENT TEXT]

Length: [Brief/Medium/Comprehensive]
Focus: [SPECIFIC ASPECTS IF ANY]

Provide:
1. Executive summary (2-3 sentences)
2. Key points (bullet points)
3. Main conclusions or recommendations
4. Important details not to miss
```

## Meeting Notes Summary
```
Summarize these meeting notes:

[PASTE MEETING NOTES]

Extract:
1. Meeting purpose and attendees
2. Key discussion points
3. Decisions made
4. Action items with owners and deadlines
5. Open questions or concerns
6. Next steps
```

## Research Paper Summary
```
Summarize this research paper:

[PASTE PAPER OR PROVIDE DETAILS]

Include:
1. Research question/hypothesis
2. Methodology
3. Key findings
4. Conclusions
5. Significance and implications
6. Limitations
7. Future research directions

Target audience: [Academic/General/Practitioner]
```

## Email Thread Summary
```
Summarize this email thread:

[PASTE EMAIL THREAD]

Provide:
1. Main topic/issue
2. Participants and their positions
3. Key points raised
4. Decisions or agreements reached
5. Unresolved items
6. Required actions
```

## Article Summary with Key Takeaways
```
Summarize this article and extract key takeaways:

[PASTE ARTICLE]

Format:
- Title and source
- Brief summary (100 words)
- Key takeaways (3-5 bullet points)
- Relevance to: [YOUR CONTEXT]
- Actionable insights
```

## Book Summary
```
Summarize this book:

Book: [TITLE AND AUTHOR]
Content: [CHAPTERS OR FULL TEXT]

Provide:
1. Overview and main thesis
2. Chapter-by-chapter breakdown
3. Key concepts and frameworks
4. Important quotes
5. Practical applications
6. Critical evaluation
7. Who should read this book

Length: [BRIEF/COMPREHENSIVE]
```

## Technical Documentation Summary
```
Summarize this technical documentation:

[PASTE TECHNICAL DOC]

Extract:
1. Purpose and scope
2. Key features/capabilities
3. System requirements
4. Usage instructions (high-level)
5. Important limitations or considerations
6. Where to find detailed info

Audience: [Technical/Non-technical]
```

## News Summary
```
Summarize recent news about:

Topic: [TOPIC]
Sources: [PASTE ARTICLES OR LIST SOURCES]
Time Period: [DATES]

Provide:
1. Overview of major developments
2. Key events in chronological order
3. Different perspectives/opinions
4. Implications and significance
5. What to watch next
```

## Video/Podcast Summary
```
Summarize this video/podcast:

Title: [TITLE]
Duration: [LENGTH]
Content: [PASTE TRANSCRIPT OR DESCRIBE]

Provide:
1. Overview and main topic
2. Key points with timestamps
3. Important quotes or insights
4. Conclusions

```

## Legal Document Summary
```
Summarize this legal document:

Document Type: [CONTRACT/AGREEMENT/POLICY/etc.]
[PASTE DOCUMENT]

Extract:
1. Purpose and parties involved
2. Key terms and conditions
3. Rights and obligations
4. Important dates and deadlines
5. Financial terms
6. Termination conditions
7. Risks or concerns to flag

Note: Present in plain language for non-legal audience.
```

## Multi-Document Synthesis
```
Synthesize insights from multiple documents:

Documents:
[PASTE OR LIST DOCUMENTS]

Topic: [COMMON THEME]

Provide:
1. Common themes across documents
2. Differing viewpoints or contradictions
3. Comprehensive overview of the topic
4. Gaps in coverage
5. Integrated conclusions
6. Most credible/authoritative sources
```

## Executive Briefing
```
Create an executive briefing on:

Topic: [TOPIC]
Source Material: [PASTE CONTENT]
Audience: [EXECUTIVES/BOARD/etc.]

Format:
- Situation overview (what happened)
- Impact and implications
- Options or recommendations
- Next steps
- Risk factors

Length: 1 page maximum, decision-focused.
```

## Changelog Summary
```
Summarize this changelog/release notes:

[PASTE CHANGELOG]

Group by:
1. Major new features
2. Significant improvements
3. Breaking changes requiring action
4. Important bug fixes
5. Deprecations
6. Impact on users/developers
7. Migration steps if needed
```

## Comparison Summary
```
Compare and summarize these options:

Options:
[PASTE OR DESCRIBE OPTIONS]

Criteria: [WHAT TO COMPARE]

Provide:
- Comparison table
- Key differences highlighted
- Pros and cons of each
- Recommendation based on criteria
- Summary of best use case for each option
```

## Historical Timeline Summary
```
Create a timeline summary of:

Topic: [SUBJECT]
Sources: [INFORMATION]
Time Period: [RANGE]

Provide:
- Chronological timeline of key events
- Context for each event
- Cause and effect relationships
- Turning points

```
