# Research Prompts

## Literature Review
```
Conduct a literature review on:

Topic: [RESEARCH TOPIC]
Scope: [SPECIFIC ASPECTS TO COVER]
Time Period: [YEARS]
Field: [ACADEMIC DISCIPLINE]

Provide:
1. Overview of current state of research
2. Key theories and frameworks
3. Major findings and consensus areas
4. Gaps in current research
5. Conflicting viewpoints
6. Emerging trends
7. Recommendations for further research
8. Key citations to explore
```

## Market Research
```
Conduct market research for:

Product/Service: [NAME]
Target Market: [DESCRIBE]
Geography: [LOCATION]
Competitors: [LIST IF KNOWN]

Research:
1. Market size and growth potential
2. Target audience characteristics
3. Customer needs and pain points
4. Competitive landscape
5. Market trends
6. Barriers to entry
7. Pricing strategies
8. Go-to-market recommendations
```

## Competitive Analysis
```
Analyze competitors for:

Our Product/Service: [DESCRIBE]
Competitors: [LIST COMPETITORS]
Comparison Criteria: [WHAT TO COMPARE]

Provide:
1. Competitor profiles
2. Feature comparison matrix
3. Pricing comparison
4. Strengths and weaknesses analysis
5. Market positioning
6. Differentiation opportunities
7. Competitive advantages we can leverage
8. Threats to address
```

## User Research Plan
```
Create a user research plan for:

Product/Feature: [NAME]
Research Goals: [WHAT YOU WANT TO LEARN]
Target Users: [USER SEGMENTS]
Timeline: [TIMEFRAME]

Include:
1. Research questions
2. Methodology (interviews, surveys, usability tests, etc.)
3. Participant recruitment criteria
4. Sample size and composition
5. Research protocol/script
6. Data collection methods
7. Analysis approach
8. Expected deliverables
```

## Technology Evaluation
```
Evaluate technology options for:

Use Case: [DESCRIBE NEED]
Requirements: [LIST REQUIREMENTS]
Options to Evaluate: [LIST TECHNOLOGIES]
Constraints: [BUDGET, TIME, RESOURCES]

Compare:
1. Features and capabilities
2. Performance and scalability
3. Learning curve and documentation
4. Community and support
5. Cost (licensing, maintenance, training)
6. Integration capabilities
7. Security and compliance
8. Long-term viability

Provide recommendation with rationale.
```
